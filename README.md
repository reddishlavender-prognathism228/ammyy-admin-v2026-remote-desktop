## 🛠 Troubleshooting common issues

If you encounter problems, check these items:

* No Connection: Verify that both computers have an active internet link. Check if a local firewall blocks the program.
* Slow Performance: Close background applications that consume high amounts of bandwidth, such as streaming services or large update downloads.
* Screen Blackout: Change the color settings in the software menu to a lower quality. This reduces the amount of data the software sends over the network.
* Error Messages: Restart the application on both computers to clear any temporary glitches in the connection service.
